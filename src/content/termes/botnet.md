Una **botnet** és una xarxa de dispositius infectats per malware —ordinadors, mòbils, càmeres, routers...— que un atacant controla remotament de manera centralitzada, normalment sense que els propietaris legítims dels dispositius se n'adonin.

Cada dispositiu infectat es coneix informalment com un "bot" o "zombi". Les botnets s'utilitzen sovint per llançar atacs de denegació de servei distribuïda (DDoS), enviar spam massiu o distribuir més malware.

## Com protegir-te

Actualitza el firmware de routers i dispositius domèstics connectats, canvia les contrasenyes per defecte i evita instal·lar programari de fonts no fiables, que és la via d'entrada més habitual.
